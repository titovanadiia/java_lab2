# Лабораторна робота №2 — Створення класів в Java

## Варіант
* **Завдання 1 (п. 14):** `Triangle` — трикутник (сторони, кути, периметр, площа, висоти, визначення виду трикутника)[cite: 5, 6].
* **Завдання 2 (п. 4):** `SimpleTriangle` — трикутник за трьома сторонами з перевіркою можливості існування, периметром, площею та порівнянням[cite: 6].
* **Завдання 3 (п. 9):** `Complex` — комплексні числа (додавання, віднімання, множення, ділення, модуль, аргумент; 4 числа в аргументах командного рядка або введення в консолі)[cite: 8].

## Структура проєкту
* `Triangle.java` — реалізація класу `Triangle`[cite: 6].
* `SimpleTriangle.java` — реалізація класу `SimpleTriangle`[cite: 6].
* `Complex.java` — реалізація класу `Complex`[cite: 8].
* `Main.java` — демонстрація роботи конструкторів, статичних членів, методів, `toString`, `equals` та інтерактивного вводу[cite: 3, 4].

## Запуск
1. Відкрити проєкт у VS Code або IntelliJ IDEA (потрібен встановлений JDK).
2. Запустити клас `Main` (`java_lab2.Main`).
3. Ввести необхідні значення в консолі згідно з підказками (або передати 4 числа через аргументи командного рядка для `Complex`)[cite: 8].
